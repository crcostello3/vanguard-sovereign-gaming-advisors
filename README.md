# Vanguard Sovereign Gaming Advisors LLC

A Next.js website for Vanguard Sovereign Gaming Advisors LLC.

## Run it locally

You need Node.js installed.

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Deploy to Vercel

1. Create a GitHub repository.
2. Upload this project to GitHub.
3. Go to Vercel and import the GitHub repository.
4. Vercel will detect Next.js automatically.
5. Click Deploy.

No environment variables are required for this first version.

## Customize

The main page content is in `app/page.tsx`.
Design and responsive styling are in `app/globals.css`.
Website metadata is in `app/layout.tsx`.

A professional founder photo can replace the placeholder in the Leadership section later.
